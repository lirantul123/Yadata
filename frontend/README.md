# Yadata Frontend

The frontend is a web application built with React, TypeScript, and Vite. Users input property details to get estimated apartment/house prices.

---

## Running the Frontend

1. Install dependencies:
```bash
npm install
```
2. Run in development mode:
```bash
npm run dev
```
#### Server runs on http://localhost:5173

### Using the Frontend

A. Enter property details in the form:

* Size

* Location

* Number of rooms

* Age

* Parking availability

B. Submit the form.

C. View the predicted price on the results page.
